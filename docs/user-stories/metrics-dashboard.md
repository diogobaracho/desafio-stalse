# Metrics dashboard

**As** a team lead, **I want** to see ticket volume per day and the mix by category, channel, priority and status, **so that** I can plan staffing and spot problem areas.

**Why these metrics:** volume per day drives shift planning; top categories show where self-service or product fixes would cut demand; channel mix guides staffing per channel; the priority and status mix shows urgency and backlog health; dropped invalid dates show data quality.

**Acceptance criteria**
- Cards show valid records, rows read, invalid dates dropped and the period. Tables show top categories, by channel, by priority, by status and by day.
- A visible note says the numbers were **generated by the ETL pipeline**, with source file and "data as of".
- An unavailable file gives an error state ("Execute o pipeline de ETL…"); zero records give an empty state.
- The API serves the precomputed file; nothing is calculated per request.

- The by-day table scrolls inside its card (the Kaggle data covers 730 days).

**Delivered by:** Kaggle CSV (`make kaggle-download`) → `data/etl.py` → `data/processed/metrics.json` → `GET /metrics` → `/dashboard` (`MetricsView`).
